(https://creativecommons.org/licenses/by-sa/2.1/jp/).

Changes made for Steel Prep: muscles only, triangle count reduced for phones, exported as a single GLB file
with `tools/blender-export.py`. In keeping with the ShareAlike terms, the derived model is published here
